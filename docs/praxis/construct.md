# Praxis Construct Contract

## Why ThoughtGarden exists

ThoughtGarden exists to encourage critical and analytical thinking. It should help a user make a belief explicit, encounter serious alternatives, inspect assumptions, confront contradictions, revise positions when warranted, and decide which unresolved thread to pull next.

It is not primarily an answer engine.

## What Praxis is

Praxis is the collective result of a governed deliberation between three philosophical reasoning lenses. Praxis is not a hidden fourth mind.

The initial governed minds are Platonic, Nietzschean, and Faustian.

The orchestrator may validate, schedule, persist, and deterministically resolve protocol state. It may not invent philosophical authority or numerically rank one worldview as the winner.

## Five-phase bounded deliberation

1. **Independent Thesis** — each mind answers independently before seeing the others' positions.
2. **Challenge** — each mind identifies a strong point, challenged assumption, objection, and question.
3. **Revision** — each mind declares its position maintained, revised, partially conceded, or withdrawn.
4. **Consensus Proposal** — each mind proposes a complete candidate Praxis response it believes all three can defend.
5. **Ratification** — each mind ratifies, ratifies with reservation, or rejects every candidate.

The orchestrator advances only when all three minds have submitted for the current phase.

## Praxis response

### Consensus Core

What all three perspectives can defend after deliberation.

### Remaining Tensions

Where the frameworks still disagree, qualify the consensus, or identify unresolved assumptions.

### Critical Question

The strongest next question the user should confront.

If no candidate response is unanimously admissible, the engine must not fabricate consensus. An unresolved result is valid.

## Epistemic contract

- Historical claims must cite the approved corpus supplied to that mind.
- Textual evidence and philosophical extrapolation must be distinguishable.
- A model must not claim a historical thinker literally held a modern proposition without evidence.
- Minds must represent opposing arguments charitably before criticism.
- Revision is evidence of functioning deliberation, not failure.
- Disagreement is preserved when justified.
- Hidden chain-of-thought is neither requested nor stored. Observable reasoning is represented through structured claims, evidence references, objections, revisions, proposals, ratifications, and outputs.

## Memory direction

Future memory is layered:

1. immutable canonical philosophical corpus and constitutions;
2. thread memory for the current inquiry;
3. Praxis inquiry history containing prior claims, tensions, and consensus;
4. optional user philosophical history containing propositions the user has expressed and revised.

Historical constitutions remain governed and stable. Prior conversations are evidence about earlier inquiries, not silent rewrites of Plato, Nietzsche, or Goethe.
